# 🚀 JavaScript Quiz Platformasi (23-27 Mavzular)

Ushbu loyiha JavaScript bo'yicha 5 ta asosiy mavzuni qamrab oluvchi 20 ta test savolidan iborat zamonaviy interaktiv test platformasidir.

## 📌 Qamrab olingan mavzular:
1. **23. JavaScript :** JavaScript nima?: Console, alert bilan muloqot (1-4 savollar)
2. **24. JavaScript :** O'zgaruvchilar: let, const, string, number (5-8 savollar)
3. **25. JavaScript :** Array va Object — ma'lumot turlari (9-12 savollar)
4. **26. JavaScript :** Shartli operatorlar if, else, mantiqiy amallar (13-16 savollar)
5. **27. JavaScript :** Funksiyalar — Kodni qayta ishlatish (17-20 savollar)

---

## 🌟 Asosiy imkoniyatlar:
- 👤 **O'quvchi ma'lumotlari:** Testga kirishda o'quvchi o'zining ismi, familiyasi va guruhini kiritadi.
- ⏱️ **Taymer:** 25 daqiqalik orqaga sanash taymeri.
- 🧭 **Navigatsiya xaritasi:** 1 dan 20 gacha bo'lgan savollarni xohlagan tartibda ochish va qaysi biri yechilganini ko'rish.
- 📊 **Google Sheets integratsiyasi:** Har bir o'quvchi testni yakunlaganda uning natijasi (Ism, Familiya, Nechta to'g'ri ishlagani, Foiz, Baho, Sarflangan vaqt) to'g'ridan-to'g'ri Google Sheets jadvaliga tushadi.
- 📋 **Xatolar tahlili (Review):** O'quvchi test yakunida qaysi savollarga to'g'ri, qaysilariga xato javob berganini to'liq izohlar bilan ko'ra oladi.

---

## 📁 Loyiha tarkibi:
- `index.html` — Asosiy veb-sahifa
- `style.css` — Dizayn va animatsiyalar
- `questions.js` — 23-27 mavzular bo'yicha 20 ta test savollari
- `app.js` — Test tizimi va Google Sheets yuborish mantiqi
- `google-apps-script.js` — Google Sheets uchun tayyor Apps Script kodi
- `GOOGLE_SHEETS_QOLLANMA.md` — Google Sheets-ga ulash bo'yicha qadamma-qadam qo'llanma
